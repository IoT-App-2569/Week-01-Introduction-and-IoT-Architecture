หมวด A — ข้อที่ 1: Introduction to IoT

Question

คุณคือ TA วิชา 03376134 APPLICATIONS OF INTERNET OF THINGS  
หน้าที่ของคุณคือทำการ audit คำตอบของฉันตามเกณฑ์ต่อไปนี้:

คำถาม:  
“อธิบายว่า Internet of Things (IoT) คืออะไร และยกตัวอย่างระบบ IoT ที่พบในชีวิตประจำวัน พร้อมอธิบายว่าทำไมระบบนั้นจึงถือเป็น IoT”

กรุณาตรวจคำตอบของฉันตาม rubric ต่อไปนี้:

1) ความถูกต้องของเนื้อหา (40%)  
   - อธิบายความหมายของ IoT ถูกต้องหรือไม่  
   - ตัวอย่างที่ยกมาเป็น IoT จริงหรือไม่  
   - อธิบายเหตุผลว่าทำไมระบบนั้นเป็น IoT ได้ถูกต้องหรือไม่  

2) ความครบถ้วนของคำอธิบาย (30%)  
   - มีทั้งนิยาม + ตัวอย่าง + เหตุผลประกอบ  
   - มีความเข้าใจเชิงระบบหรือไม่  

3) ความเป็นภาษามนุษย์ (Human Authenticity) (30%)  
   - ตรวจว่าคำตอบของฉันมีลักษณะภาษาที่ AI ชอบใช้หรือไม่ เช่น  
     • การใช้ ":" มากเกินไป  
     • การใช้ emoji  
     • การใช้ bullet point แบบ textbook  
     • การใช้ประโยคสูตรสำเร็จ เช่น “ดังนั้น”, “อย่างไรก็ตาม”, “กล่าวคือ”  
   - ตรวจว่ามีความเป็นธรรมชาติของมนุษย์หรือไม่  
   - ตรวจว่ามีการอธิบายด้วยภาษาของตัวเองหรือไม่  
   - ตรวจว่ามีความผิดพลาดเล็กน้อยแบบมนุษย์หรือไม่ (เป็นเรื่องปกติ)

ให้คะแนนทั้งสามหมวด พร้อมคำอธิบายเหตุผลอย่างละเอียด  
และสรุปคะแนนรวม 100 คะแนน

สุดท้าย ให้ข้อเสนอแนะว่าฉันควรปรับปรุงตรงไหนเพื่อให้ได้คะแนนสูงขึ้น

Answer

Internet of Things หรือ IoT ถ้าแปลกันตรงๆ แบบเข้าใจง่าย มันคือระบบที่เอา "สิ่งของ" รอบตัวเรามารวมร่างกับ "อินเทอร์เน็ต" ครับ ทำให้ของชิ้นนั้นไม่ได้ทำงานทื่อๆ อยู่กับที่อีกต่อไป แต่มันสามารถเก็บข้อมูล ส่งข้อมูล และคุยกับอุปกรณ์ชิ้นอื่นหรือคุยกับเราได้ผ่านเครือข่าย โดยที่เราไม่จำเป็นต้องไปกดปุ่มเปิดปิดหน้าเครื่องด้วยตัวเองตลอดเวลา
ตัวอย่างระบบ IoT ในชีวิตประจำวัน: ระบบไฟอัจฉริยะ (Smart Lighting)
ลองนึกถึงหลอดไฟเปลี่ยนสีได้ที่เราควบคุมผ่านแอปในมือถือ หรือตั้งเวลาให้มันเปิดปิดเองตอนเราไม่อยู่บ้านครับ
ทำไมระบบไฟอัจฉริยะถึงถือว่าเป็น IoT?
ถ้าเป็นหลอดไฟธรรมดา มันจะทำงานได้ก็ต่อเมื่อมีคนเดินไปกดสวิตช์ไฟที่กำแพง (ตัดต่อวงจรไฟฟ้าโดยตรง) แต่พอเป็น Smart Light มันกลายเป็น IoT เพราะมันมีองค์ประกอบของระบบครบเลยครับ
มีสมองกลและตัวรับสัญญาณในตัวเอง: ตัวหลอดไฟไม่ได้มีแค่ไส้ไฟ แต่มีชิปคอมพิวเตอร์ขนาดเล็กและตัวรับสัญญาณ Wi-Fi หรือ Bluetooth ฝังอยู่ข้างใน
เชื่อมต่ออินเทอร์เน็ต: หลอดไฟเชื่อมต่อกับเลาเตอร์ที่บ้าน ทำให้มันมีตัวตนบนโลกออนไลน์
สื่อสารและรับคำสั่งได้: เวลาเราอยู่นอกบ้านแล้วสั่ง "ปิดไฟ" ผ่านแอปในมือถือ คำสั่งจะวิ่งผ่านอินเทอร์เน็ตไปที่คลาวด์ แล้วคลาวด์ก็ส่งต่อมาที่หลอดไฟที่บ้าน หรือเราอาจจะตั้งให้มันทำงานร่วมกับเซนเซอร์ตรวจจับความเคลื่อนไหว พอเดินผ่านปุ๊บ ไฟก็ติดปั๊บ

คำถาม:  
“อธิบายโปรโตคอลในชั้น Application Layer ที่ใช้ในระบบ IoT เช่น MQTT, AMQP, XMPP

Answer

จุดต่างสำคัญ
MQTT เน้น "เบาและประหยัด" ส่งแค่ข้อมูลดิบสั้นๆ ไม่กินไฟ ไม่เปลืองเน็ต
AMQP เน้น "ชัวร์และปลอดภัย" มีระบบคิวรองรับ ข้อมูลไม่มีทางหาย แต่กินพลังงานสูง
XMPP เน้น "เช็กสถานะ" เหมือนแอปแชท รู้ทันทีว่าอุปกรณ์ไหนออนไลน์อยู่ แต่ไฟล์ข้อมูลจะใหญ่กว่าเพื่อน
สถานการณ์ใช้งานจริง
ถ้าจะทำระบบวัดสภาพอากาศในป่าลึก:
มีแค่เซนเซอร์ตัวเล็กๆ ใช้ไฟจากโซลาร์เซลล์อันจิ๋ว คอยส่งตัวเลขอุณหภูมิกลับมา แบบนี้ต้องใช้ MQTT เพราะเน็ตในป่ามันช้าและจำกัด ตัวนี้ประหยัดพลังงานที่สุดแล้วครับ
ถ้าจะทำระบบจ่ายเงินหรือเช็กสต็อกสินค้า:
ข้อมูลห้ามหายเด็ดขาด แม้เน็ตจะหลุดไปเสี้ยววิ ระบบก็ต้องเก็บข้อมูลไว้ในคิวก่อน พอเน็ตมาค่อยส่งต่อให้ธนาคารหรือโกดัง แบบนี้ต้อง AMQP เพื่อความปลอดภัยระดับองค์กร
ถ้าจะทำระบบเปิด-ปิดไฟในบ้านผ่านมือถือ:
เราอยากกดสั่งในแอปแล้วเห็นทันทีว่าไฟดวงไหนเปิดอยู่ ดวงไหนปิดอยู่ หรือหลอดไฟขาดไปแล้ว (ออฟไลน์) แบบนี้ใช้ XMPP จะดีมาก เพราะมันเด่นเรื่องการเช็กสถานะสดๆ ตลอดเวลาครับ

Answer

IoT WorldForum (IoTWF) ได้กำหนดสถาปัตยกรรมอ้างอิงมาตราฐาน แบบ 7 ชั้น (7-Layer IoT Reference Model) ขึ้นมา เพื่อช่วย Developer และองค์กรสามารถมองเห็นภาพรวมของระบบ IoT ที่มักจะมีความซับซ้อนสูง ให้กลายเป็นโครงสร้างที่เข้าใจง่ายและเป็นระบบ

- Layer 1 Physical Devices and Things อุปกรณ์กายภาพ ชั้น hardware จริง เช่น Sensor กับ  Actuators อุปกรณ์สวมใส่ หรือ เครื่องจักรในโรงงาน ทำหน้าที่เก็บข้อมูลจากโลกจริงหรือรับคำสั่งไปปฏิบัติการ
- Layer 2 Connectivity ชั้นที่ดูแลเรื่องการสื่อสารและส่งผ่านข้อมูลระหว่างอุปกรณ์ใน Layer 1 ไปยังระบบเครือข่าย โดยใช้โปรโตคอลต่างๆ เช่น Wi-Fi Bluetooth หรือ Cellular (4G/5G)
- Layer 3: Edge Computing การประมวลผลที่ขอบเครือข่าย ชั้นที่คัดกรอง แปลงรูปแบบ และประมวลผลข้อมูลในด่านแรกทันทีที่ใกล้กับแหล่งกำเนิดข้อมูล เพื่อลดปริมาณข้อมูลที่จะส่งไปคลาวด์และลดความหน่วง
- Layer 4: Data Accumulation การสะสมและจัดเก็บข้อมูล** ชั้นที่เปลี่ยนข้อมูลที่กำลังวิ่งอยู่ ให้กลายเป็นข้อมูลที่หยุดนิ่งเพื่อจัดเก็บ โดยจะทำการบันทึกข้อมูลลงในฐานข้อมูล หรือระบบ Storage ที่พร้อมใช้งาน
- Layer 5: Data Abstraction การจัดการและสรุปข้อมูล** ชั้นที่ทำหน้าที่รวมรวบและเตรียมข้อมูลจากหลายแหล่ง ล้างข้อมูลที่ไม่สมบูรณ์ และจัดฟอร์แมตให้อยู่ในรูปแบบที่แอปพลิเคชันในชั้นบนสามารถเรียกใช้ได้อย่างมีประสิทธิภาพและปลอดภัย
- Layer 6: Application แอปพลิเคชัน ชั้นของซอฟต์แวร์ แอปพลิเคชัน หรืออินเทอร์เฟซ ที่ทำหน้าที่นำข้อมูลที่ผ่านการประมวลผลและจัดฟอร์แมตแล้วจากชั้นล่าง Layer 5 เปลี่ยนให้เป็นหน้าจอแดชบอร์ด ปุ่มกด หรือระบบแจ้งเตือนที่มนุษย์สามารถใช้งานได้จริง เป็นจุดที่ระบบ IoT มีปฏิสัมพันธ์กับผู้ใช้งาน**
- Layer 7: Collaboration and Processes** ชั้นสูงสุดของสถาปัตยกรรม เป็นจุดที่ คนนำข้อมูลและข้อสรุปจากแอปพลิเคชันไปใช้ทำงานร่วมกัน หรือใช้ในการตัดสินใจทางธุรกิจ รวมถึงการเชื่อมต่อข้อมูล IoT เข้ากับระบบบริหารงานเดิมขององค์กร เพื่อให้เกิดการดำเนินงานโดยอัตโนมัติ

การแบ่งแยกทำให้ developer ไม่จำเป็นต้องรู้ทุกเรื่องพร้อมกัน แต่ละคนสามารถทำงานกันในส่วนที่ถนัดได้เช่น คนทำ hardware ทำ sensor ส่วนคนทำ web-app ทำส่วนของ UI โดยเชื่อมต่อกันผ่าน interface ที่กำหนดไว้ และมีความง่ายในการบำรุงรักษา เมื่อเกิดปัญหาสามารถระบุได้ว่าเกิดจากส่วนไหน หรือ เมื่อต้องการเปลี่ยนหรืออัพเกรดระบบ เช่น อยากเปลี่ยนจาก WI-FI เป็นแบบ 5G ก็ทำการเปลี่ยนที่ Layer 2 โดยไม่ต้องทำฝั่ง Application ใหม่ 

- ขั้นที่สำคัญที่สุด คือ Layer 3 Edge Computing การประมวลผลที่ขอบเครือข่าย เพราะว่า เมื่อระบบมีขนาดใหญ่ขึ้น ถ้าเราส่งข้อมูลทั้งหมดจากอุปกรณ์นับล้านตัวขึ้นไปประมวลผลบน Cloud โดยตรง ทำให้ internet ล่ม และทำให้ค่า cloud แพง และทำให้ระบบทำงานช้า สรุปมันคือ ตัวช่วยคิดและตัดสินใจแทน cloud ในเรื่องที่รีบด่วน ให้ระบบ IoT ทำงานได้ไวแบบเรียลไทม์ ปลอดภัย และ ประหยัดค่า internet ค่า cloud ได้
