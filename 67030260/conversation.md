## คำตอบ
```
Internet of Things (IoT)คือเครือข่ายที่เชื่อมต่ออุปกรณ์อิเล็กทรอนิกส์ต่างๆ เข้ากับอินเทอร์เน็ต ยกตัวอย่างระบบ IoT ที่พบในชีวิตประจำวันคือระบบรดน้ำต้นไม้อัจฉริยะ ทำไมระบบนั้นจึงถือเป็น IoTเพราะว่ามีการส่งข้อมูลผ่าน Networkข้อมูลความชื้นถูกส่งผ่านเครือข่ายไร้สาย เช่น พวกWi-FiI
```

## คำตอบ
```
MQTTจะใช้แบนด์วิดท์ต่ำ ประหยัดพลังงาน การกำหนดระดับความน่าเชื่อถือของข้อมูล ซึ่งจะเหมาะสมกับสถานการณ์ที่มีอุปกรณ์เซ็นเซอร์ขนาดเล็กที่ใช้พลังงานจากแบตเตอรี่และต้องการส่งข้อมูลเป็นระยะ
AMQP จะมีความปลอดภัยสูง รับประกันการส่งข้อความสำเร็จ 100เปอร์เซ็น รองรับระบบที่มีความน่าเชื่อถือระดับ Enterprise ซึ่งจะเหมาะสมกับสถานการณ์ที่มีระบบควบคุมอุตสาหกรรมขนาดใหญ่
XMPP จะรองรับการสื่อสารแบบเรียลไทม์ สามารถระบุสถานะได้ โครงสร้างยืดหยุ่นขยายระบบได้ง่าย ซึ่งจะเหมาะสมกับสถานการณ์ที่มีอุปกรณ์ที่ต้องการโต้ตอบกับผู้ใช้งานโดยตรง หรือระบบที่ต้องการส่งข้อความโต้ตอบแบบทันที

```

MQTT

กล่าวถึงระดับความน่าเชื่อถือของข้อมูล (QoS) ได้ถูกต้อง แม้ไม่ได้ระบุคำว่า QoS โดยตรง

XMPP

## คำตอบ

```
1.Physical Devices Layer จุดเริ่มต้นของระบบ ประกอบด้วยเซ็นเซอร์และแอคชูเอเตอร์ที่โต้ตอบกับโลกจริง ทำหน้าที่เก็บข้อมูลและส่งต่อ
2.Connectivity Layer ทำหน้าที่นำข้อมูลจากอุปกรณ์ส่งผ่านเครือข่ายไปยังระบบส่วนกลาง
3. Edge Computing Layer การประมวลผลข้อมูล แปลงรหัส และกรองข้อมูลเบื้องต้นทันที ณ จุดที่ใกล้กับอุปกรณ์ เพื่อลดปริมาณข้อมูลที่ต้องส่งขึ้นคลาวด์
4.Data Accumulation Layer การจัดเก็บข้อมูลในระยะสั้นหรือยาว เพื่อเตรียมข้อมูลให้อยู่ในรูปแบบที่พร้อมสำหรับการวิเคราะห์
5.Data Abstraction Layer การรวมข้อมูลจากหลายแหล่งเข้าด้วยกัน (Data Aggregation) แปลงข้อมูลให้อยู่ในฟอร์แมตมาตรฐาน
6.Application Layer ซอฟต์แวร์ที่แปลผลข้อมูลเป็น Dashboard แจ้งเตือน หรือควบคุมอุปกรณ์
7.Collaboration and Processes Layer ชั้นธุรกิจที่นำข้อมูลเชิงลึกไปใช้งานจริง โดยส่งข้อมูลต่อไปยังผู้ปฏิบัติงานหรือระบบองค์กร เพื่อประกอบการตัดสินใจและการทำงานอัตโนมัติ

  ทำไมการแบ่งชั้นแบบนี้จึงช่วยให้การออกแบบชัดเจนขึ้น?
ช่วยขจัดความสับสนโดยการแบ่งส่วนระบบ (Decomposition) ทำให้ทีมต่างๆ สามารถทำงานเฉพาะด้านได้โดยไม่ต้องรอส่วนอื่นๆ เสร็จสิ้น  ช่วยให้สามารถเลือกใช้ฮาร์ดแวร์หรือซอฟต์แวร์จากผู้ผลิตที่ต่างกันมาเชื่อมต่อกันได้ (Interoperability) อีกทั้งยังช่วยระบุจุดเกิดปัญหา (Troubleshooting) และตั้งค่าระบบรักษาความปลอดภัยในแต่ละรอยต่อได้อย่างแม่นยำ

   คิดว่าชั้นที่สำคัญที่สุด: Layer 1 - Physical Devices Layer
เหตุผล เป็นรากฐานสำคัญที่สุดของระบบ เพราะหากไม่มีชั้นนี้ (ไม่มีเซ็นเซอร์เก็บข้อมูลที่แม่นยำ หรือแอคชูเอเตอร์ที่ทำงานได้ตรงจุด) ระบบจะไม่สามารถรับรู้สภาพแวดล้อมที่แท้จริงได้ ข้อมูลที่ส่งไปยังชั้นอื่นๆ ทั้งหมดจะไม่มีอยู่จริง เช่น เซ็นเซอร์วัดความชื้นในดิน
```
